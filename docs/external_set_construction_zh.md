# 外部验证数据：TCM-BEST4SDT 辨证论治病例

本目录的数据由公开数据集 **TCM-BEST4SDT** 的辨证论治任务（`TCM_SDT.json`，300 例）转换而来，用于 eval_v2 的外部验证（方案第十六节）。

## 出处与许可

- 数据集：TCM-BEST4SDT。正式存档于 Figshare（DOI 10.6084/m9.figshare.30615956）；本研究使用 GitHub 仓库（https://github.com/DYJG-research/TCM-BEST4SDT ，提交 60407f2）中的 `TCM_SDT.json`，文件 SHA256 为 d94711ac60db83e3a33c2c46b1d6efbf072565a22e8fd464f5f61b444860de59。病例来源于临床病例与名家医案；标准答案由中医专家标注，经标注者交叉验证和第三方评议委员会审定。
- 引用：Li K, Guo J, Shang Z, Liu Y, Du H, Liu L, Zhao Y, Dong L. *A benchmark dataset for evaluating Syndrome Differentiation and Treatment in large language models.* arXiv:2512.02816, 2025.
- 许可：数据集以 CC BY 4.0 发布，代码仓库为 Apache-2.0。论文与数据发布时须注明出处，并说明本研究对数据做了下述转换。

## 文件

| 文件 | 内容 | 谁会读取 |
|---|---|---|
| `external_questions_all.json` | 300 道题：病例原文 + 题型指令；参考要点 | 问答模型只看到题目；评审看到题目与参考要点 |
| `external_reference.jsonl` | 标准答案原文（证型、病因、病机、病性、病位、治则治法、处方）与处方药名 | 只用于服务器上识别并排除“病例自身的原始记录”，以及事后分析；不交给任何模型 |
| `BUILD_MANIFEST.json` | 来源文件哈希、转换规则、计数 | 记录 |

由 `analysis/build_external_set.py` 生成；同一来源文件重跑，输出逐字节相同。

## 转换规则（确定性规则，没有人工或 AI 修改）

1. **每例一题。** 题型按病例编号的哈希固定分配：诊断题 148 道、治则题 152 道。题干 = 病例原文（只去掉首尾空白）+ 与封存集逐字相同的题型指令：
   - 诊断题：“请解释该病例的诊断、证候与病因病机。”
   - 治则题：“请说明适用于该病例的治疗原则，不要求方药剂量。”
2. **参考要点全部摘自专家标准答案：**
   - 诊断题：疾病诊断（“中医疾病诊断”字段）、证候（“证型”字段拆成证候要素，最多 3 个）、病机（“病机”字段的前 2 个合格分句）；
   - 治则题：治疗原则（“治则治法”字段拆分）。
   - 细则见 `BUILD_MANIFEST.json` 的 `rules`。
3. **录入错误。** 只更正 1 处明显错误：病例 168 的“白庁”→“白疕”（该例病史为银屑病）。
4. **分层（预先规定）。** 编号 1–150 为名家医案改写与教材式病例（classical），151–300 为现代临床病例（modern）。
5. **服务器上的进一步处理**（`server/build_external.py`）：
   - 排除与 CE 训练病例近重复（字符 2–3 元 TF-IDF 余弦 ≥ 0.85）的病例，以及集内近重复的病例；
   - 用与封存集完全相同的 BM25 设置建立 20 条候选证据；
   - 排除病例自身的原始记录（规则见方案第十六节）。

## 与封存集的区别

- 参考要点来自数据集专家的标准答案，没有经过本研究的标注与仲裁；要点粒度按规则对齐封存集（2–12 字的术语短语）。
- 没有证据支持标签，所以外部验证只比较答案层的要点召回（KPR），不做检索层和机制分析。
- 病例原文保持原样。其中一部分病例的叙述里已经带有提示答案的词句（如“显示体内存在热证”），`leak_flags` 字段列出了这些分句，只用于报告，不据此排除。
