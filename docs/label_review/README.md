# Clinician review of the sealed-set labels

**Purpose:** to estimate the quality of the sealed-set labels (LLM pre-annotation with adjudication; the 161 full-support disagreements were separately confirmed by a TCM expert).

| Item | Value |
|---|---|
| Sample | 44 of 176 questions (25%), stratified by question type and case source, drawn by a fixed SHA-256 rule (`expert_review_v1`); 134 required points; all 880 candidates (2,680 candidate–point labels) |
| Reviewer | One clinician co-author (a Western-medicine clinician with a working knowledge of TCM) |
| Format | Confirmatory: the reviewer saw the existing labels, marked each point as correct, to be revised or to be deleted, and corrected the candidate labels they disagreed with |
| Main results | 100 of 124 judged points correct (80.6%); 703 of 880 candidates unchanged; three-level support agreement 94.8% (κ = 0.79); full-support precision 1.00 and recall 0.54; relevance agreement 94.2%; condition-mismatch agreement 89.5% |

`aggregate.json` holds all aggregate figures, including the exploratory re-analysis of strict coverage with the reviewer's labels.

The review was not registered. The labels used in all analyses were not changed. Item-level review results are withheld together with the sealed-set labels.
