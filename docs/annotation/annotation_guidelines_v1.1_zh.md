# 中医问答证据支持标注规范 v1.1

适用于：专家封存测试集 expert_testset_v1（阶段0 校准、阶段1 题目与要点核验、阶段2 证据支持标注）。
修订日期：2026-10-24。

## 一、任务是什么

每道题给出一个**病例背景**和一个问题，题型有两种：

- **诊断解释题**：问该病例的诊断、证候与病因病机。
- **治疗原则题**：问适用于该病例的治疗原则，不涉及方药剂量。

研究要回答的是：检索到的材料里，哪些能**支撑**回答这道题所必需的要点，而不只是与题目主题相关。标注员的工作分两步：

1. 阶段1：确定每道题的**必要回答要点**。
2. 阶段2：逐条判断每段候选证据对每个要点的支持程度。

正式独立标注时，所有判断只依据表中给出的文字及本规范已冻结的术语尺度，**不上网检索，不与其他标注员讨论具体题目**。校准阶段可以共同核验参考材料并形成有出处的术语约定；参考材料不能补写候选中没有的症状、舌脉、诊断、因果或治则，也不能成为正式标注时临时寻找的额外证据。

## 二、核心概念

| 概念 | 定义 |
|---|---|
| 必要回答要点 | 回答本题必须给出、能用文字核对的单一断言。分四类：疾病诊断（中医病名）、证候、病机、治疗原则 |
| 完整支持（2） | 证据文本明确表达了该要点或其公认同义表述，且适用条件与本病例相容 |
| 部分支持（1） | 只支持要点的一部分、只描述表现而没有点明，或只支持更宽/更窄的相近概念 |
| 不支持（0） | 没有涉及该要点，或只是主题相关 |
| 相关性 | 证据是否与本病例的疾病、证候、主要症状或所问治则主题相关，与能否支持无关 |
| 同病异证或条件不符 | 候选与本题疾病或可比较的核心主症相关，并有明确的不同证型或不相容条件；缺少信息本身不计为条件不符 |

## 三、阶段1：题目与要点核验

### 3.1 纳入或排除（题目核验表）

**纳入（填1）需同时满足：**

- 病例背景足以进行辨证；
- 原始辨证分析给出了与题型对应的明确内容：
  - 诊断解释题需要明确的诊断、证候或病机；
  - 治疗原则题需要明确的治则。

**排除（填0），并在“排除原因”中写明以下之一：**

- **参考不足**：原始分析没有可作为答案的明确内容；治则不得根据方药反推。
- **超出范围**：问题实际涉及方药剂量、针灸操作、人物或文献识记，或属于纯西医内容。
- **信息不足**：关键病情信息缺失，且无法从原始病情描述中补全。
- **参考不可靠**：原始分析自相矛盾，或明显不是中医辨证。

### 3.2 答案泄露

“检索用问题文本”是之后用来检索证据、输入模型的文字，不能提前透露答案。

**需要删除的内容：**

- 证候名，例如“证属肝郁脾虚”；
- 医生的病机推断，例如“寒气侵袭太阳经络，导致项痛”；
- 中医诊断结论，例如“中医诊断为胸痹”；
- 治则。

**应当保留的内容：** 症状、体征、舌脉、病程、既往史、检查结果，以及客观诱因（例如“受凉后出现”）。

**西医诊断：** 作为病史信息可以保留。如果西医诊断名与中医病名相同，同时也是主诉（例如“头痛”“胃痛”），不必删除。

**填写方法：**

- 有泄露，填1，并把要删除的片段**从问题文本中原样复制**到对应列。多处用 `||` 分隔。
- 删除前请确认该片段在问题文本中能原样找到，否则脚本无法执行删除。
- 表中“自动标记的疑似泄露片段”只是程序提示，请自行判断。

**补充病情信息：** 如果问题文本漏掉了舌脉等关键信息，可以从“原始病情描述”中原样复制，填到“应补充的关键病情信息”列。

### 3.3 要点核验（要点核验表）

草拟要点由程序从原始辨证分析中抽取，**不是金标**，请逐条判定：

| 判定 | 何时使用 | 要填写的内容 |
|---|---|---|
| 1 保留 | 准确、必要、表述规范 | 无 |
| 2 修改后保留 | 措辞需要规范；复合要点需要拆分；长句需要精简 | 在“修改后内容”中写新要点，多条用“；”分隔。类型变化时填写“修改后类型” |
| 0 删除 | 非必要、重复、占位句（例如“以上是治疗方案”）、与题型不符、原文没有而属于推断 | 无 |

**要点写法：**

- 每条要点是一个单一断言，通常 2 到 15 个字。
  - 例如：疾病诊断“胸痹”；证候“气阴两虚”；病机“肝失疏泄”；治疗原则“疏肝健脾”。
- 病机长句精简为1到3条核心病机，例如“湿热内阻”“热迫血行”。省去症状结局和重复病名，但不删掉本题必要的病因机制。若病后、手术或化疗与脏腑受损之间的关系是原文明确的核心内容，应保留这一关系。
- “气不摄血”等能够独立核验的核心机制可以成为要点，即使原文随后解释出血症状；“描述症状如何产生的叙述不算要点”指不保留冗长症状叙述，不是删去全部因果病机。
- 并列的独立治法要拆开：“益气养阴，清热利湿”拆成两条。一个既定治法单位如“辛开苦降”“清热化湿”“理气除满”“通阳泄浊”“豁痰开结”本轮整体保留，不拆成单字动作；评分2仍须覆盖其全部语义。
- 一个完整复合证候如“血虚气滞寒凝”本轮整体保留；拆分治法的规则不机械用于拆散证候。仅覆盖其中一项，最高1。
- 诊断解释题只保留疾病诊断、证候、病机三类；治疗原则题只保留治疗原则。
- 不得引入原始辨证分析和治疗记录中没有的内容，也不得凭方药反推治则。
- 每题建议 2 到 5 条要点。原文确实只有一条明确治则时，可以只有一条。

**补充遗漏要点：** 在题目核验表的“遗漏的必要要点”列中填写，格式为 `类型:内容`，多条用“；”分隔。例如：`证候:气滞血瘀；病机:瘀阻胞脉`。

### 3.4 修改内容、类型及去重（本轮新增）

1. 优先忠实保留原文明确且可用的证候，不为统一字面而任意换证名。“脾虚失运”与“脾虚湿阻”有共同成分，但不能在所有情况下当作完全同义。
2. “脾虚失运，水湿不化”可分别核验；水湿不化属于运化障碍的病机表述，不因出现在“中医证候”后的句子中就一律新建证候标签。草拟类型明显不合适时应修改类型并说明。
3. 原文已有的要点，无论在修改栏还是遗漏栏提出，都先合并后再审核。按内容去重，不按填入位置决定是否为新要点；上位概括与细化说明若没有独立必要信息，不重复计权。同一病理过程的不同环节不能仅因词近自动合并。
4. 不为了凑足2至5条而增补。“正气难复”等泛化病程描述，已有更具体虚损机制时通常不另立必要要点。“脏气受损、气血阴阳耗伤”可压缩为保留原意的一个机制表述，不能无依据扩展病位。
5. 原始分析有局部不严谨时，记录问题，保留有明确依据且不受错误影响的断言；关键结论依赖错误、无法分离时交仲裁或排除。例如CAL2不把乏力、气短归因于胃气上逆，不把仅见于分析的口腻补进病情描述，也不补造原始病情未提供的脉象。
6. 校准时同时核对“保留/修改/删除”及修改后的最终内容、类型、拆分和遗漏。现有阶段1一致性脚本只比较判定码等指标，不能证明修改后的要点已一致。

## 四、阶段2：证据支持标注

每行是一道题加一段候选证据。证据顺序已经随机打乱，与检索排名无关。

**以该版证据表中实际显示的P编号、类型和全文为评分对象。** 阶段1修改、拆分或新增要点，不会自动改变已发出的阶段2表。负责人须先冻结最终要点，重建对应证据表并重新独立评分；不得把旧P3长句的分数移到新P3短句上。
本轮校准旧表CAL2-P4仍是“胃气上逆导致呃逆”，不是仅“胃气上逆”；只论上逆致恶心不能判为完整支持整个旧要点。

### 4.1 逐要点打分（P1、P2 等列）

每个可判断的要点填2、1或0；确实无法判断的字段按4.2节处理。表中显示NA的列表示该题没有这个要点，请保持不动。

**完整支持（2）的条件：**

- 证据明确写出该要点，或使用公认同义表述，例如“肝肾不足”与“肝肾亏虚”。
- 适用条件相容，属于以下情况之一：
  - 针对同一疾病或同类证候表现的论述；
  - 教材中关于该证、该治则的一般性论述。
- 病机要点要求证据表达该核心机制；“胃气上逆”等本身就是机制表述，不要求固定出现“导致”二字。但要点含特定病因或结局时，完整支持必须覆盖该关系；只出现关键词不算。
- “完整支持”同时要求内容完整及条件可比。病名相同、疾病西医名称相同、出现同一关键词，都不足以单独判2。病名不同也不自动排除2：若目标是共同证候或机制，且相应条件可比，可以判2。
- 证据来自“其他患者病例记录”时，须在候选中找到相关主症及可比较的舌脉资料，且不与目标要点所需条件冲突，才可判2。本病例未提供脉象时，不要求候选匹配一个不存在的脉象；已有的关键舌象和主症仍需可比。缺少足够症状舌脉的诊断摘要，不能因病名相同判2，明确覆盖的内容最高1。
- 对疾病诊断、证候、病机分别检查条件。候选明确“胃积”而证型不同，可给病名的有限支持1；不同证型不自动抹去病名信息，也不自动否定所有独立要点。与某要点直接相反的内容，该要点判0。
- 不机械要求全部症状、舌象和脉象逐字一致。非关键差异可容许；明显寒热虚实冲突、病位或适应条件冲突不能忽略。给2时在备注列出覆盖短语及可比依据。

**部分支持（1）的情况：**

- 只支持复合要点的一部分，例如要点为“肝郁脾虚”，证据只提到肝郁。
- 只描述了相应表现，没有点明证候或病机。
- 有明确共同病理成分但不等义，例如“血虚”之于“肝郁血虚”；“肾气不固”与“肾阳不足”只按相近的肾虚成分给有限支持，不能当同义词。
- 跨疾病的明确共同成分可以给1，例如肾气不足之于脾肾亏虚、肝气郁结之于血虚气滞寒凝中的气滞。须指出实际覆盖哪个成分，不能只凭“虚”“湿”“瘀”等单字联想。
- 只有症状时，须形成与目标相应的症状组合或有直接对应的主症关系；孤立舌淡、脉细、乏力不够。“食少便溏、乏力、舌淡”等组合可有限提示脾虚失运；恶心呕吐可有限对应胃气上逆，不能据此补出完整因果。一般湿邪征象如苔腻可有限提示内湿，但不能自动证明特定症状的全部成因。
- 条件缺失时，明确已有的内容仍可给1；条件直接否定目标断言时为0。若存在其他不相容条件，但另有能单独指出的共同成分，可保留该成分的1，并在备注说明限制。

**不支持（0）的情况：**

- 没有涉及该要点；
- 只是主题相关；
- 否定或排除性表述，例如“非湿热所致”“禁用清热”。
- 病名不同而未建立公认同义或上下位关系，仅症状相近，疾病诊断本身判0。例如脱疽不能直接支持脉痹；其气滞或寒凝成分可另对证候给1。
- “血瘀”不自动等于“血虚”或“气滞”，“痰凝”不自动等于“寒凝”，“胃失和降”不自动覆盖特定的“上逆导致呃逆”。
- 治疗原则不得根据病机、证候、方名、药味或针灸穴位反推；只写湿热中阻而未写清热化湿，治则仍为0。

### 4.2 其他列

- **相关性**：满足任一明确联系填1：同病；相同或直接相近的核心主症；明确共同证候/病机成分；所问治法的明确共同作用。可以相关但所有P均为0。仅共同人口特征、单个非特异体征，或偶然共同的无关既往史不足以填1。候选明确提及本题主要疾病，即使仅在既往史出现，本轮仍按宽口径主题相关填1，并备注“仅病史”；不据此提高支持度。诊断解释题“眩晕/头晕”“出血”属于可识别主题联系，不能因中医病名不同一概判相关性0。
- **同病异证或条件不符**：须同时说明可比较的疾病/核心主症或拟迁用的治法，以及明确不同的证型或不相容条件。缺症状、缺舌脉、缺治则、单纯异病不自动填1；此时0只表示未见明确不符，不能读作已证实相容。明确异证可以填1，不必等到已经有人给2。仅候选有证名、本题只给治则时，不能凭治则反推出本题隐藏证型后判异证。
- **无法判断**：只在残缺、矛盾或术语歧义使某个应判断字段无法可靠赋值时填1，并在备注点明字段及受影响片段。末尾截断但所需断言已完整出现，填0；无目标治则且已足以判不支持，也不因无关病机错句填1。受影响的支持度/相关性/条件列留空待仲裁，不把不明一律填0；仍可确定的其他列照常填写。不要使用NA代替待判断，NA只用于不存在的P列。
- **备注**：推荐格式为“P2=1：原句……覆盖……，缺……；条件标记依据……”。给2必须说明覆盖和条件依据。不得只写“相近”“条件不同”而没有可核对内容。
- **交叉核对**：任一P为1或2时，相关性应为1；全部P为0时相关性仍可能为1。条件不符不是整行支持度归零开关；逐要点判断。无法判断=1且仍填满所有受影响字段时，应先核对是否实际可以判断。

## 五、操作要求

1. 只填写表头带【填】的列。不要改动其他列，也不要删行、排序或改编号。
